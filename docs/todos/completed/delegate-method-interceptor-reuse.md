# Delegate Stubs: Reuse MethodInterceptorRenderer

**Status:** Complete
**Priority:** Medium
**Created:** 2026-02-05
**Last Updated:** 2026-02-05

---

## Problem

Delegate stubs (Pattern 7) use a separate hand-rolled interceptor in `InlineRenderer.RenderDelegateStub` (~850 lines) instead of the shared `MethodInterceptorRenderer`. This causes:

1. **No async auto-wrapping** — `delegate Task<int> AsyncOperation(int x)` requires `Returns(Task.FromResult(42))` instead of `Returns(42)`. The generator can see the return type wraps `Task<T>` but doesn't unwrap it.
2. **No sequence support** — No `ThenCall`, `ThenReturns`, `Returns(first, params rest)`.
3. **No fluent builder** — `OnCall()` returns `void` instead of a builder (no `.Verifiable()` chaining).
4. **Duplicated When chain rendering** — ~600 lines of delegate-specific When classes that duplicate MethodInterceptorRenderer's When logic.

The current justification ("the delegate type IS the contract") is weak — the generator inspects `Task<T>` for interface methods identically.

## Solution

Replace the delegate-specific interceptor rendering with `MethodInterceptorRenderer`. A delegate maps cleanly to `UnifiedMethodInterceptorModel` as "a single non-overloaded method with no declaring interface and no user method." **No modifications to MethodInterceptorRenderer are needed.**

## Results / Conclusions

Implementation successful. Delegates now use the shared MethodInterceptorRenderer, gaining:
- Async auto-wrapping (`Returns(42)` for `Task<int>` delegates)
- Sequence support (`Returns(first, params rest)`, `ThenCall`, `ThenReturns`)
- Fluent builder chaining (`OnCall(...).Verifiable()`)
- Proper Strict mode (via `IncludeStrictParameter: true`)
- When chains generated by shared renderer (eliminating ~666 lines of duplicate code)

One behavioral change: When chain calls no longer count toward `TotalCallCount` on the interceptor. This aligns with how interface stubs work (verify on chain, not interceptor). One test updated to use `chain.Verify()` instead of `stub.Interceptor.Verify()`.
