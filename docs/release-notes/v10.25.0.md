# KnockOff v10.25.0

**Release Date:** 2026-01-22
**Breaking Changes:** Yes

---

## Summary

Removes `WasCalled` from public method interceptor APIs and adds `Verify()` methods directly on method interceptors for consistency with property interceptors.

---

## What's New

### Breaking: Removed WasCalled from Public API

`WasCalled` properties have been removed from method tracking interfaces and generated interceptors. This completes the API simplification started in v10.24.0, guiding users toward the more expressive verification API.

**Removed APIs:**
- `IMethodTracking.WasCalled` interface property
- Generated method interceptor `WasCalled` properties
- Generated generic method handler `WasCalled` properties

### Added: Verify() Methods on Method Interceptors

Method interceptors now have `Verify()` and `Verify(Times)` methods directly available, matching the API pattern already used by property and indexer interceptors.

**Before:**

```csharp
var stub = new UserRepositoryStub();
stub.GetById(1);

// Using WasCalled boolean
Assert.True(stub.GetById.WasCalled);

// Or checking via OnCall tracking
var tracking = stub.GetById.OnCall(id => { });
stub.GetById(1);
Assert.True(tracking.WasCalled);
```

**After:**

```csharp
var stub = new UserRepositoryStub();
stub.GetById(1);

// Direct verification on interceptor (throws if not called)
stub.GetById.Verify();

// With Times constraint
stub.GetById.Verify(Times.Once);
stub.GetById.Verify(Times.AtLeast(1));

// Verify never called
stub.OtherMethod.Verify(Times.Never);
```

## Migration Guide

Update assertions to use the verification API:

| Old Pattern | New Pattern |
|-------------|-------------|
| `Assert.True(stub.Method.WasCalled)` | `stub.Method.Verify()` |
| `Assert.False(stub.Method.WasCalled)` | `stub.Method.Verify(Times.Never)` |
| `if (stub.Method.WasCalled) { ... }` | Use `Verify()` or catch `VerificationException` |
| `Assert.True(tracking.WasCalled)` | `tracking.Verify()` |
| `Assert.False(tracking.WasCalled)` | `tracking.Verify(Times.Never)` |

**Examples:**

```csharp
// Before
Assert.True(stub.Connect.WasCalled);

// After
stub.Connect.Verify();
```

```csharp
// Before
Assert.False(stub.Disconnect.WasCalled);

// After
stub.Disconnect.Verify(Times.Never);
```

```csharp
// Before - checking if method was called in conditional
if (stub.Connect.WasCalled)
{
    // Connection was established
}

// After - verification throws if not called
try
{
    stub.Connect.Verify();
    // Connection was established
}
catch (VerificationException)
{
    // Not called
}
```

## Technical Details

**Interfaces Modified:**
- `IMethodTracking.cs` - Removed `WasCalled` property

**Generator Changes:**
- `MethodInterceptorRenderer.cs` - Removed `WasCalled`, added `Verify()` methods to interceptors
- `FlatRenderer.cs` - Removed `WasCalled` from generic handlers
- `InlineRenderer.cs` - Removed `WasCalled` from generic handlers, added `Verify()` to delegate interceptors
- `ClassRenderer.cs` - Removed `WasCalled` (already had `Verify()` methods)

**Documentation:**
- `verification.md` - Removed incorrect WasGot/WasSet references, added migration section

---

## API Consistency

All interceptor types now have consistent verification APIs:

| Interceptor Type | Verify() | Verify(Times) | VerifyGet() | VerifySet() |
|-----------------|----------|---------------|-------------|-------------|
| Properties | Yes | Yes | Yes | Yes |
| Indexers | Yes | Yes | Yes | Yes |
| Methods | Yes | Yes | N/A | N/A |
| Delegates | Yes | Yes | N/A | N/A |
