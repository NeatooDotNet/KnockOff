# v0.39.0

**Release Date:** 2026-02-07
**Breaking Changes:** Yes

## Summary

Singular method API naming — all method configuration methods now use singular form for consistency. Generic typed handlers unified with the same Return/Call naming.

## What's New

### Breaking: Singular Method API Naming

All method configuration APIs now use singular form:

| v0.38.0 | v0.39.0 |
|---------|---------|
| `.Returns(callback)` | `.Return(callback)` |
| `.ThenReturns(callback)` | `.ThenReturn(callback)` |
| `.Execute(callback)` | `.Call(callback)` |
| `.ThenExecute(callback)` | `.ThenCall(callback)` |
| `.Returns(value)` on When chains | `.Return(value)` |

Interface types renamed:

| v0.38.0 | v0.39.0 |
|---------|---------|
| `IMethodReturnsBuilder<T>` | `IMethodReturnBuilder<T>` |
| `IMethodReturnsSequence<T>` | `IMethodReturnSequence<T>` |
| `IMethodExecuteBuilder<T>` | `IMethodCallBuilder<T>` |
| `IMethodExecuteSequence<T>` | `IMethodCallSequence<T>` |

### Breaking: Generic Typed Handler Rename

The `.Of<T>().OnCall()` API for generic methods is now split by return type:

| v0.38.0 | v0.39.0 |
|---------|---------|
| `.Of<T>().OnCall(callback)` (non-void) | `.Of<T>().Return(callback)` |
| `.Of<T>().OnCall(callback)` (void) | `.Of<T>().Call(callback)` |

## Migration

Search and replace:

1. `.Returns(` → `.Return(` (non-void method callbacks and values)
2. `.ThenReturns(` → `.ThenReturn(`
3. `.Execute(` → `.Call(` (void method callbacks)
4. `.ThenExecute(` → `.ThenCall(`
5. `.OnCall(` → `.Return(` or `.Call(` (generic typed handlers)
