# v10.31.0 - Source Delegation Bug Fix

**Release Date:** 2026-01-27
**NuGet:** [KnockOff 10.31.0](https://nuget.org/packages/KnockOff/10.31.0)

## Overview

Fixes a bug where `Source(IList<T>)` and similar base interface overloads didn't correctly delegate to members declared on transitive base interfaces for inline stubs.

## Bug Fix

### Source Delegation for Inherited Interface Members

When calling `.Source(List<T>)` on an inline stub, C# overload resolution picks `Source(IList<T>)` (since `List<T>` implements `IList<T>`). Previously, this overload only delegated members declared directly on `IList<T>`, missing members from transitive base interfaces like `IEnumerable<T>`.

**Before (broken):**

```csharp
[KnockOff<IMyList>]  // where IMyList : IList<string>
public partial class MyTests { }

var stub = new MyTests.Stubs.IMyList();
var source = new List<string> { "a", "b", "c" };

// C# picks Source(IList<string>) overload
stub.Source(source);

// GetEnumerator is declared on IEnumerable<T>, not IList<T>
// This threw: "No implementation provided for GetEnumerator"
foreach (var item in stub)  // FAILED!
{
    Console.WriteLine(item);
}
```

**After (fixed):**

```csharp
// Now works correctly - delegates to source.GetEnumerator()
foreach (var item in stub)  // Works!
{
    Console.WriteLine(item);  // Outputs: a, b, c
}
```

### Affected Members

For `Source(IList<T>)`, delegation now correctly includes:
- `IList<T>` members: Indexer, IndexOf, Insert, RemoveAt
- `ICollection<T>` members: Count, Add, Clear, Contains, CopyTo, Remove, IsReadOnly
- `IEnumerable<T>` members: GetEnumerator
- `IEnumerable` members: non-generic GetEnumerator

## Breaking Changes

None. This is a bug fix that makes Source delegation work as originally intended.

## Technical Notes

- Added `InterfaceHierarchy` field to `InterfaceInfo` to capture the full inheritance graph
- Transform phase now builds hierarchy entries for each interface in the inheritance chain
- `InlineModelBuilder.BuildSourceProviders` uses the hierarchy to correctly identify inherited interfaces
