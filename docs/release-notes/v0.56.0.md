# v0.56.0 — Shadowed Property Interception Fix

**Released:** 2026-04-20
**Breaking Changes:** No

## Summary

Bug fix: interface hierarchies that use the C# `new` modifier to shadow a property with a different accessor set now produce compiling stubs. The generated interceptor exposes the **union** of accessors across all shadowed declarations; explicit interface implementations still route through that one interceptor using each face's own accessor set.

## What's Fixed

Previously, declaring a narrowing interface like:

```csharp
public interface IInterfaceWide { int Prop { get; set; } }
public interface IInterfaceNarrow : IInterfaceWide { new int Prop { get; } }

[KnockOff<IInterfaceNarrow>]
public partial class NarrowingInlineStub { }
```

produced uncompilable generated code:

```
error CS1061: 'PropertyGetInterceptor<int>' does not contain a definition for 'InvokeSet'
```

The interceptor was typed from whichever declaration the generator saw first (get-only), while the explicit implementation for `IInterfaceWide.Prop` still emitted a setter that invoked `InvokeSet` on the get-only interceptor.

## Resolution

Two pipelines fixed independently:

| Pipeline | File | Change |
|---|---|---|
| Inline (patterns 5, 7, 8) | `src/Generator/Builder/InlineModelBuilder.cs` | Property dedup now unions `HasGetter`/`HasSetter` across declarations sharing a name. |
| Flat (patterns 1, 2) | `src/Generator/Renderer/FlatRenderer.cs` | Interceptor rendering picks a union-accessor representative per `InterceptorClassName`. |

Source(T) fallback emission was extended correspondingly — `SetSourceFallback` now matches the union interceptor's overload, binding `null` for accessors that are not declared on the source face.

## Behavior Guarantees

- `stub.Prop.Get(...)` and `stub.Prop.Set(...)` are each available whenever any shadowed declaration has the matching accessor.
- Reading via the narrow face invokes the shared interceptor's getter.
- Writing via the wide face invokes the shared interceptor's setter, and `LastSetValue` reflects the value.
- `VerifyGet` / `VerifySet` count invocations across all faces.
- `Source(IInterfaceNarrow)(real)` binds only to accessors declared on the narrow face.

## Scope

Covered patterns: 1, 2, 5, 7, 8 (all interface-based pipelines).
