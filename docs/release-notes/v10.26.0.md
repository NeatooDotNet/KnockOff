# KnockOff v10.26.0

**Release Date:** 2026-01-22
**Breaking Changes:** Yes

---

## Summary

Removes `GetCount`, `SetCount`, `AddCount`, and `RemoveCount` from public property, indexer, and event interceptor APIs to complete the API simplification started in v10.24.0 (methods) and v10.25.0 (WasCalled removal).

---

## What's New

### Breaking: Removed Count Properties from Public API

Count properties have been removed from public interceptor APIs for:
- **Property interceptors:** `GetCount` and `SetCount` are now internal
- **Indexer interceptors:** `GetCount` and `SetCount` are now internal
- **Event interceptors:** `AddCount` and `RemoveCount` are now internal

These properties encouraged low-level assertions instead of the more expressive verification API.

**Before:**

```csharp
var stub = new ServiceStub();
IService service = stub;

service.Name = "Test";
_ = service.Name;

// Low-level assertions using count properties
Assert.Equal(1, stub.Name.SetCount);
Assert.Equal(1, stub.Name.GetCount);

// Event count assertions
service.OnCompleted += (s, e) => { };
Assert.Equal(1, stub.OnCompleted.AddCount);
```

**After:**

```csharp
var stub = new ServiceStub();
IService service = stub;

service.Name = "Test";
_ = service.Name;

// Idiomatic verification using Verify API
stub.Name.VerifySet(Times.Once);
stub.Name.VerifyGet(Times.Once);

// Event verification
service.OnCompleted += (s, e) => { };
stub.OnCompleted.VerifyAdd(Times.Once);
```

## Migration Guide

Update assertions to use the verification API:

### Property Interceptors

| Old Pattern | New Pattern |
|-------------|-------------|
| `Assert.Equal(1, stub.Property.GetCount)` | `stub.Property.VerifyGet(Times.Once)` |
| `Assert.Equal(n, stub.Property.GetCount)` | `stub.Property.VerifyGet(Times.Exactly(n))` |
| `Assert.Equal(0, stub.Property.GetCount)` | `stub.Property.VerifyGet(Times.Never)` |
| `Assert.Equal(1, stub.Property.SetCount)` | `stub.Property.VerifySet(Times.Once)` |
| `Assert.Equal(n, stub.Property.SetCount)` | `stub.Property.VerifySet(Times.Exactly(n))` |
| `Assert.Equal(0, stub.Property.SetCount)` | `stub.Property.VerifySet(Times.Never)` |

### Indexer Interceptors

| Old Pattern | New Pattern |
|-------------|-------------|
| `Assert.Equal(n, stub.Indexer.GetCount)` | `stub.Indexer.VerifyGet(Times.Exactly(n))` |
| `Assert.Equal(n, stub.Indexer.SetCount)` | `stub.Indexer.VerifySet(Times.Exactly(n))` |

### Event Interceptors

| Old Pattern | New Pattern |
|-------------|-------------|
| `Assert.Equal(1, stub.Event.AddCount)` | `stub.Event.VerifyAdd(Times.Once)` |
| `Assert.Equal(n, stub.Event.AddCount)` | `stub.Event.VerifyAdd(Times.Exactly(n))` |
| `Assert.Equal(0, stub.Event.AddCount)` | `stub.Event.VerifyAdd(Times.Never)` |
| `Assert.Equal(1, stub.Event.RemoveCount)` | `stub.Event.VerifyRemove(Times.Once)` |
| `Assert.Equal(n, stub.Event.RemoveCount)` | `stub.Event.VerifyRemove(Times.Exactly(n))` |
| `Assert.Equal(0, stub.Event.RemoveCount)` | `stub.Event.VerifyRemove(Times.Never)` |

**Examples:**

```csharp
// Before - Property
Assert.Equal(2, stub.Name.GetCount);

// After
stub.Name.VerifyGet(Times.Exactly(2));
```

```csharp
// Before - Event
Assert.Equal(1, stub.DataReceived.AddCount);
Assert.Equal(1, stub.DataReceived.RemoveCount);

// After
stub.DataReceived.VerifyAdd(Times.Once);
stub.DataReceived.VerifyRemove(Times.Once);
```

```csharp
// Before - Reset clears counts
stub.Property.Reset();
Assert.Equal(0, stub.Property.GetCount);

// After
stub.Property.Reset();
stub.Property.VerifyGet(Times.Never);
```

## Technical Details

Count tracking has been changed from public to internal visibility:

**Generator Changes:**
- `FlatRenderer.cs` - Changed property, indexer, and event count properties to internal
- `InlineRenderer.cs` - Changed property, indexer, and event count properties to internal
- `ClassRenderer.cs` - Changed property, indexer, and event count properties to internal

Internal count tracking remains functional to support:
- `VerifyGet(Times)` / `VerifySet(Times)` API implementation
- `VerifyAdd(Times)` / `VerifyRemove(Times)` API implementation
- Internal verification for `Stub.Verify()` and `Stub.VerifyAll()` methods

---

## API Consistency

All interceptor types now have consistent verification APIs:

| Interceptor Type | Count Properties | Verification API |
|-----------------|-----------------|------------------|
| Properties | Internal | `VerifyGet(Times)`, `VerifySet(Times)`, `Verify(Times)` |
| Indexers | Internal | `VerifyGet(Times)`, `VerifySet(Times)`, `Verify(Times)` |
| Events | Internal | `VerifyAdd(Times)`, `VerifyRemove(Times)`, `Verify(Times)` |
| Methods | Internal (since v10.24.0) | `Verify(Times)` |
