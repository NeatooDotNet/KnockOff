# KnockOff v0.27.0

**Release Date:** 2026-01-26
**Breaking Changes:** Yes

---

## Summary

Major API unification release that standardizes callback configuration to method syntax across all interceptor types (properties, indexers, methods, and delegates). Removes the `.Value` property in favor of value-based overloads that simplify common stubbing scenarios. Adds new sequence and tracking APIs for advanced scenarios.

---

## What's New

### Breaking: Unified OnGet/OnSet to Method Syntax

Property and indexer callback configuration now uses method syntax instead of property assignment, enabling return of tracking interfaces for sequencing and verification.

**Before:**
```csharp
stub.Property.OnGet = () => "value";
stub.Property.OnSet = (val) => Console.WriteLine(val);
stub[key].OnGet = () => 42;
```

**After:**
```csharp
stub.Property.OnGet(() => "value");
stub.Property.OnSet((val) => Console.WriteLine(val));
stub[key].OnGet(() => 42);
```

**Benefits:**
- Returns `IPropertyTracking` / `IIndexerTracking` for chaining verification
- Enables sequence methods: `OnGetSequence()`, `ThenGet()`, `ThenSet()`
- Consistent with existing `OnCall()` method syntax
- Renamed `RecordGet`/`RecordSet` → `InvokeGet`/`InvokeSet` for clarity

### Breaking: Delegate OnCall Method Syntax

Delegate stub callback configuration now uses method syntax instead of property assignment.

**Before:**
```csharp
stub.Interceptor.OnCall = (args) => result;
```

**After:**
```csharp
stub.Interceptor.OnCall((args) => result);
```

**Benefits:**
- Consistent API across all interceptor types
- Enables future tracking/sequencing features for delegates

### Breaking: Value Property Removed - Value-Based Overloads Added

The `.Value` property has been removed from all interceptors. Use value-based overloads for simpler stub configuration.

**Before:**
```csharp
stub.Name.Value = "John";
stub.GetUser.OnCall = () => user;
stub.IsActive.OnGet = () => true;
```

**After:**
```csharp
stub.Name.OnGet("John");
stub.GetUser.OnCall(user);
stub.IsActive.OnGet(true);
```

**Features:**
- Method overloads: `OnCall(TReturn value)` - no need for `() => value` lambda
- Property overloads: `OnGet(T value)` - replaces `.Value` property
- Indexer overloads: `OnGet(T value)` - simplified indexer stubbing
- Delegate overloads: `OnCall(TReturn value)` - simplified delegate stubbing
- Sequence overloads: `ThenCall(value)`, `ThenGet(value)`, `ThenSet(action)`
- Async methods automatically wrap values: `OnCall(user)` → `Task.FromResult(user)`

## Migration Guide

### 1. Property and Indexer OnGet/OnSet Migration

Replace property assignment with method calls:

| Old Pattern | New Pattern |
|-------------|-------------|
| `stub.Property.OnGet = () => value` | `stub.Property.OnGet(() => value)` |
| `stub.Property.OnSet = (val) => { }` | `stub.Property.OnSet((val) => { })` |
| `stub[key].OnGet = () => value` | `stub[key].OnGet(() => value)` |
| `stub[key].OnSet = (val) => { }` | `stub[key].OnSet((val) => { })` |
| `stub.Property.RecordGet()` | `stub.Property.InvokeGet()` |
| `stub.Property.RecordSet(val)` | `stub.Property.InvokeSet(val)` |

**Example:**
```csharp
// Before
stub.Name.OnGet = () => "John";
stub.Name.OnSet = (val) => Console.WriteLine($"Set to: {val}");

// After
stub.Name.OnGet(() => "John");
stub.Name.OnSet((val) => Console.WriteLine($"Set to: {val}"));
```

### 2. Delegate OnCall Migration

Replace property assignment with method call:

| Old Pattern | New Pattern |
|-------------|-------------|
| `stub.Interceptor.OnCall = (args) => result` | `stub.Interceptor.OnCall((args) => result)` |
| `stub.Interceptor.OnCall = args => result` | `stub.Interceptor.OnCall(args => result)` |

**Example:**
```csharp
// Before
stub.Factory.OnCall = (id) => new User(id);

// After
stub.Factory.OnCall((id) => new User(id));
```

### 3. Value Property Removal Migration

Replace `.Value` property with value-based overloads:

| Old Pattern | New Pattern |
|-------------|-------------|
| `stub.Property.Value = value` | `stub.Property.OnGet(value)` |
| `stub.Method.OnCall = () => value` | `stub.Method.OnCall(value)` |
| `stub.Property.OnGet = () => value` | `stub.Property.OnGet(value)` |
| `stub[key].OnGet = () => value` | `stub[key].OnGet(value)` |

**Examples:**

```csharp
// Properties - Before
stub.Name.Value = "John";
stub.IsActive.Value = true;

// Properties - After
stub.Name.OnGet("John");
stub.IsActive.OnGet(true);
```

```csharp
// Methods - Before
stub.GetUser.OnCall = () => user;
stub.GetCountAsync.OnCall = () => Task.FromResult(42);

// Methods - After
stub.GetUser.OnCall(user);
stub.GetCountAsync.OnCall(42); // Auto-wraps in Task.FromResult
```

```csharp
// Sequences - Before
stub.GetValue.OnCall = () => 1;
stub.GetValue.Sequence.Add(() => 2);
stub.GetValue.Sequence.Add(() => 3);

// Sequences - After
stub.GetValue.OnCall(1).ThenCall(2).ThenCall(3);
```

## New Features

### Tracking Interfaces

Callback methods now return tracking interfaces:

```csharp
// Method tracking
IMethodTracking tracking = stub.GetUser.OnCall(user);
tracking.ThenCall(otherUser); // Sequence support

// Property tracking
IPropertyTracking tracking = stub.Name.OnGet("John");
tracking.ThenGet("Jane"); // Sequence support

// Indexer tracking
IIndexerTracking tracking = stub[0].OnGet(42);
tracking.ThenGet(43); // Sequence support
```

### Sequence Methods

Simplified sequence configuration:

```csharp
// Method sequences
stub.GetValue.OnCallSequence()
    .ThenCall(1)
    .ThenCall(2)
    .ThenCall(3);

// Property sequences
stub.Name.OnGetSequence()
    .ThenGet("First")
    .ThenGet("Second")
    .ThenGet("Third");

// Indexer sequences
stub[key].OnGetSequence()
    .ThenGet(10)
    .ThenGet(20)
    .ThenGet(30);
```

### Invoke Methods (Renamed from Record)

```csharp
// Property
string value = stub.Property.InvokeGet(); // Was: RecordGet()
stub.Property.InvokeSet("value");         // Was: RecordSet(value)

// Indexer
int value = stub[key].InvokeGet();        // Was: RecordGet()
stub[key].InvokeSet(42);                  // Was: RecordSet(value)
```

## Technical Details

### Generator Changes

**Property/Indexer Unified Rendering:**
- New `PropertyInterceptorRenderer.cs` - shared property interceptor rendering
- New `IndexerInterceptorRenderer.cs` - shared indexer interceptor rendering
- New `ModelAdapters.cs` - adapters for unified rendering
- `UnifiedPropertyInterceptorModel.cs` - shared property model
- `UnifiedIndexerInterceptorModel.cs` - shared indexer model

**Value-Based Overload Support:**
- `MethodInterceptorRenderer.cs` - added value-based `OnCall(TReturn)` overloads
- `PropertyInterceptorRenderer.cs` - added value-based `OnGet(T)` overloads
- `IndexerInterceptorRenderer.cs` - added value-based `OnGet(T)` overloads
- Async method overloads auto-wrap: `OnCall(value)` → `Task.FromResult(value)`

**Delegate Rendering:**
- `InlineRenderer.RenderDelegateStub()` - changed `OnCall` from property to method

### New Public API Surface

**Tracking Interfaces:**
- `IPropertyTracking.cs` - property get/set tracking with sequence support
- `IPropertySequence.cs` - fluent property sequence building
- `IIndexerTracking.cs` - indexer get/set tracking with sequence support
- `IIndexerSequence.cs` - fluent indexer sequence building

**Generated Interceptor Methods:**
- Properties: `OnGet(Action)`, `OnGet(T)`, `OnSet(Action<T>)`, `InvokeGet()`, `InvokeSet(T)`
- Indexers: `OnGet(Func)`, `OnGet(T)`, `OnSet(Action)`, `InvokeGet()`, `InvokeSet(T)`
- Methods: `OnCall(T value)` overloads for all method signatures
- Delegates: `OnCall(Action)` method (was property)

## API Consistency

All interceptor types now use consistent method-based callback configuration:

| Interceptor Type | Configuration Syntax | Value Overload | Sequence Support | Tracking Return |
|-----------------|---------------------|----------------|------------------|-----------------|
| Methods | `OnCall(func)` or `OnCall(value)` | ✅ | ✅ `ThenCall(value)` | `IMethodTracking` |
| Properties | `OnGet(func)` or `OnGet(value)` | ✅ | ✅ `ThenGet(value)` | `IPropertyTracking` |
| Indexers | `OnGet(func)` or `OnGet(value)` | ✅ | ✅ `ThenGet(value)` | `IIndexerTracking` |
| Delegates | `OnCall(func)` or `OnCall(value)` | ✅ | ⏳ Future | Future |
| Events | `OnAdd(action)`, `OnRemove(action)` | N/A | N/A | Future |

## Breaking Changes Summary

1. **Property/Indexer Callbacks:** `OnGet`/`OnSet` changed from properties to methods
2. **Delegate Callbacks:** `OnCall` changed from property to method
3. **Value Property:** Removed `.Value` property - use `OnGet(value)` instead
4. **Record Methods:** Renamed to `InvokeGet()`/`InvokeSet()` for clarity
5. **Return Types:** Callbacks now return tracking interfaces instead of void

**Impact:** All code using property/indexer/delegate callback configuration requires updates. Search for `.OnGet =`, `.OnSet =`, `.OnCall =`, and `.Value =` patterns.
