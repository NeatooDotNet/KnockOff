# v0.43.0

**Release Date:** 2026-02-08
**Breaking Changes:** No

## Summary

Ref return support for methods, properties, and indexers across all applicable patterns.

## What's New

### Ref Return Support

Methods, properties, and indexers that return `ref T` or `ref readonly T` are now fully supported by the source generator. Generated interceptors correctly handle ref returns, allowing stubs to configure and verify ref-returning members.
