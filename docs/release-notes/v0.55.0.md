# v0.55.0 — Internal Type Accessibility Fix

**Released:** 2026-03-07
**Breaking Changes:** No

## Summary

Bug fix: stubbing `internal` interfaces, classes, or delegates no longer produces CS0060 compilation errors. The generator now emits stub classes with accessibility matching the target type, applied consistently across all four pipelines.

## What's Fixed

### CS0060 When Stubbing Internal Types

KnockOff hardcoded `public class` on all generated stub classes and Base helper classes. When the target type was `internal`, this caused a CS0060 compilation error because a `public` class cannot implement an `internal` interface or inherit from an `internal` class.

The fix adds accessibility resolution to each of the four independent pipelines:

| Pipeline | Renderer | Patterns | What Changed |
|----------|----------|----------|--------------|
| FlatRenderer | `FlatRenderer.cs` | 1, 2 (Standalone) | Generated `{ClassName}Base` uses user's stub class accessibility |
| StandaloneClassRenderer | `StandaloneClassRenderer.cs` | 3, 4 (Standalone Class) | Generated `{ClassName}Base` uses user's stub class accessibility |
| InlineRenderer | `InlineRenderer.cs` | 5, 7, 8 (Inline Interface, Delegate, Open Generic Interface) | Generated stub class uses target type's accessibility |
| ClassRenderer | `ClassRenderer.cs` | 6, 9 (Inline Class, Open Generic Class) | Generated wrapper stub class uses target type's accessibility |

**Standalone patterns (1-4):** The user controls stub class accessibility via their partial class declaration. The generated Base helper class now matches whatever the user declared (`public`, `internal`, etc.).

**Inline patterns (5-9):** The generator derives the stub class accessibility from the target type. An `internal` interface produces an `internal` stub class.

**Before (broken):**
```csharp
// CS0060: Base class or interface is less accessible than the class
internal interface IInternalService { string GetName(); }

[KnockOff<IInternalService>]
public partial class MyTests { }
// Generated: public class IInternalService : global::IInternalService  <-- CS0060
```

**After (fixed):**
```csharp
internal interface IInternalService { string GetName(); }

[KnockOff<IInternalService>]
public partial class MyTests { }
// Generated: internal class IInternalService : global::IInternalService  <-- compiles
```
