# v0.48.0

**Release Date:** 2026-02-09
**Breaking Changes:** No

## Summary

Bug fix for multi-parameter indexer method name generation in multi-indexer interfaces.

## What's Fixed

### Multi-Param Indexer Method Name Mismatch

When an interface has multiple indexer overloads and one has multiple parameters (e.g., `this[int a, string b]`), the generated stub body called `InvokeGet_inta_stringb` (using parameter names) but the interceptor defined `InvokeGet_Int32_String` (using type names), causing a compilation error.

**Affected:** All 4 generator pipelines (Flat, Inline Interface, Standalone Class, Inline Class) when generating stubs for interfaces with multiple indexer overloads where at least one indexer has multiple parameters.

**Root cause:** The code built a combined type string `"(int a, string b)"` including parameter names and passed it to `GetTypeSuffix()`. Fixed by adding `GetIndexerKeyTypeFriendlyName()` helper that calls `GetTypeSuffix()` per individual parameter type.
