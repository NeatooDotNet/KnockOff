# v10.30.0 - Assembly-Wide Strict Mode

**Release Date:** 2026-01-27
**NuGet:** [KnockOff 10.30.0](https://nuget.org/packages/KnockOff/10.30.0)

## Overview

Adds the `[assembly: KnockOffStrict]` attribute to enable strict mode as the default for all stubs in an assembly.

## What's New

### Assembly-Wide Strict Mode

Apply `[assembly: KnockOffStrict]` to make all stubs in your test assembly throw `StubException` for unconfigured calls by default:

```csharp
// In AssemblyInfo.cs or any file
[assembly: KnockOffStrict]

// All stubs now default to strict mode
[KnockOff<IUserService>]
public partial class UserTests { }

// Unconfigured calls throw StubException
var stub = new UserTests.Stubs.IUserService();
IUserService service = stub;
service.GetUser(42);  // Throws StubException!
```

### Opt-Out for Individual Stubs

Individual stubs can opt out of the assembly default:

```csharp
[assembly: KnockOffStrict]

// Opt out via attribute property
[KnockOff<ILegacyService>(Strict = false)]
public partial class LegacyTests { }

// Opt out via constructor (inline stubs)
var stub = new UserTests.Stubs.IUserService(strict: false);

// Opt out at runtime
stub.Strict = false;
```

### Precedence

Strict mode settings are resolved in this order (highest to lowest):

1. **Runtime:** `stub.Strict = false` or `stub.Strict()`
2. **Constructor:** `new Stubs.IService(strict: false)` (inline stubs only)
3. **Attribute:** `[KnockOff(Strict = false)]` or `[KnockOff<T>(Strict = false)]`
4. **Assembly:** `[assembly: KnockOffStrict]`
5. **Default:** `false`

## Breaking Changes

None. This is a purely additive feature.

## Technical Notes

- Assembly configuration is extracted once per compilation for performance
- The attribute only affects the assembly where it's applied (not referenced assemblies)
- Works with all stub patterns: standalone, inline interface, and inline class stubs
- Also includes a bug fix for KO0100 diagnostic not being reported for inline stubs
