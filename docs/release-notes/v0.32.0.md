# v0.32.0 - When() API & Returns Rename

**Release Date:** 2026-01-30
**NuGet:** [KnockOff 0.32.0](https://nuget.org/packages/KnockOff/0.32.0)

## Overview

This release introduces the `When()` API for parameter-specific matching and renames `OnCall(value)` to `Returns(value)` for clarity. It also simplifies callback sequencing with a builder pattern.

## Breaking Changes

### OnCall(value) → Returns(value)

The old `OnCall(value)` overload was confusing—it looked like parameter matching rather than "return this value." The new API is explicit:

**Before:**
```csharp
stub.Add.OnCall(10);  // Confusing: is 10 a parameter or return value?
```

**After:**
```csharp
stub.Add.Returns(10);  // Clear: returns 10
```

**Migration:** Find and replace `OnCall(<value>)` with `Returns(<value>)` for methods and delegates. `OnCall(callback)` remains unchanged.

### OnCallSequence → OnCall().ThenCall()

Sequence entry points are now unified with the builder pattern:

**Before:**
```csharp
stub.Calculate.OnCallSequence(x => x * 2, x => x * 3);
```

**After:**
```csharp
stub.Calculate.OnCall(x => x * 2).ThenCall(x => x * 3);
```

## New Features

### Parameter-Specific Matching with When() API

Configure different return values based on parameter values:

```csharp
stub.GetPrice.When("apple").Returns(1.50m);
stub.GetPrice.When("banana").Returns(0.75m);

Assert.Equal(1.50m, stub.GetPrice("apple"));
Assert.Equal(0.75m, stub.GetPrice("banana"));
```

**Predicate matching:**
```csharp
stub.Calculate.When(x => x > 0).Returns(100);
stub.Calculate.When(x => x < 0).Returns(-100);
stub.Calculate.When(0).Returns(0);
```

**Chaining with ThenWhen:**
```csharp
stub.Process
    .When("first").Returns("A")
    .ThenWhen("second").Returns("B")
    .ThenCall(x => x.ToUpper());  // Default for unmatched
```

**Void methods with verification:**
```csharp
stub.Log.When("error").Call(msg => errors.Add(msg));
stub.Log.Verify(Times.AtLeast(1));
```

### Builder Pattern for Callbacks

All callback methods now return builders supporting fluent chaining:

```csharp
// Methods
stub.Calculate.OnCall(x => x * 2).ThenCall(x => x * 3).ThenNone();

// Properties
stub.Name.OnGet(() => "first").ThenGet(() => "second");
stub.Value.OnSet(v => log.Add(v)).ThenSet(v => { });

// Indexers
stub.Item.OnGet((i) => i * 10).ThenGet((i) => i * 20);
```

### Async Auto-Wrapping

The When() API automatically wraps return values in Tasks for async methods:

```csharp
stub.FetchAsync.When("key").Returns("value");  // No Task.FromResult needed
var result = await stub.FetchAsync("key");     // Returns "value"
```

## Technical Notes

- Added `IMethodCallBuilder`, `IPropertyCallBuilder`, `IIndexerCallBuilder` interfaces
- Added `IWhenTracking<T>` interface for When chain configuration
- 96 new tests for When() API covering all patterns and edge cases
- 16 builder elevation tests verifying lazy sequence creation
