# v10.29.0 - Simplified Async Callbacks for Overload Groups

**Release Date:** 2026-01-27
**NuGet:** [KnockOff 10.29.0](https://nuget.org/packages/KnockOff/10.29.0)

## Overview

Extends simplified async callback support (added in v10.28.0) to methods with multiple overloads.

## What's New

### Simplified Async Callbacks for Overloaded Methods

Methods with multiple overloads now support the same simplified callback syntax:

```csharp
// Interface with overloads
interface IRepository {
    Task<User?> GetByIdAsync(int id);
    Task<User?> GetByIdAsync(int id, CancellationToken ct);
}

// Simplified callbacks - C# resolves by parameter types
stub.GetByIdAsync.OnCall((int id) => user);
stub.GetByIdAsync.OnCall((int id, CancellationToken ct) => user);

// Void async overloads work too
stub.SaveAsync.OnCall((User user) => ValidateUser(user));
stub.SaveAsync.OnCall((User user, CancellationToken ct) => ValidateUser(user));
```

## Breaking Changes

None. This is a purely additive feature.

## Technical Notes

- Different `Func<>`/`Action<>` arities are distinct C# types
- The compiler resolves the correct overload based on lambda parameter count/types
- Each `OnCall` returns per-signature tracking, so `Verify()` works correctly
- All three patterns (Standalone, Inline Interface, Inline Class) supported
