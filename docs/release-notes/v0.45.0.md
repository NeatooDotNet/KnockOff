# v0.45.0

**Release Date:** 2026-02-08
**Breaking Changes:** No

## Summary

Adds record type stub support and fixes static virtual/abstract interface member filtering.

## What's New

### Record Type Stub Support

KnockOff now supports stubbing C# `record` types across all four class stub patterns (inline class, open generic class, standalone class, generic standalone class).

**What works:**
- Records with virtual methods
- Records with explicitly declared virtual properties
- Abstract records with abstract methods
- Positional records with virtual methods
- Standalone class stubs for records (`[KnockOffBase<MyRecord>]`)

**Known limitation:** Positional record properties (e.g., `Name` and `Age` on `record Foo(string Name, int Age)`) are not interceptable via inheritance. Roslyn reports `IsVirtual=false` for these properties. Explicitly declared virtual properties on records work as expected.

**Implementation details:**
- Generator now emits `sealed record Impl` instead of `sealed class Impl` when the target type is a record
- Record-synthesized members are filtered from interceptor generation: `<Clone>$`, `EqualityContract`, `Equals`, `GetHashCode`, `ToString`, `PrintMembers`, `Deconstruct`
- `IsRecord` flag propagated through the full pipeline: Transform → Model → Builder → Renderer

### Static Virtual/Abstract Interface Member Filtering

The generator now correctly skips static virtual and static abstract members on interfaces (C# 11 static abstracts in interfaces). Previously these could cause compilation errors in generated code.
