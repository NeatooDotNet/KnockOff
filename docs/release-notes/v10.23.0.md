# KnockOff v10.23.0

**Release Date:** 2026-01-18
**Breaking Changes:** No

---

## Summary

Bug fix for init-only property set tracking in standalone stubs. The `SetCount`, `LastSetValue`, and `RecordSet()` members were missing from init-only property interceptors in the flat/stand-alone pattern.

---

## What's New

### Bug Fix: Init-Only Property Set Tracking in Standalone Stubs

Init-only property interceptors in standalone stubs now include full set tracking, matching the behavior of inline stubs.

**Before:** Standalone stub init-only properties only tracked getter access:

```csharp
public interface IEntity
{
    string Id { get; init; }
}

[KnockOff]
public partial class EntityStub : IEntity { }

var stub = new EntityStub();
// These members did NOT exist:
// stub.Id.SetCount
// stub.Id.LastSetValue
// stub.Id.RecordSet()
```

**After:** Full set tracking is available:

```csharp
var stub = new EntityStub();

// All set tracking members now exist:
Assert.Equal(0, stub.Id.SetCount);
Assert.Null(stub.Id.LastSetValue);

// RecordSet is called automatically by the init accessor
stub.Id.RecordSet("test-value");
Assert.Equal(1, stub.Id.SetCount);
Assert.Equal("test-value", stub.Id.LastSetValue);
```

This ensures consistent behavior across all three stub patterns:
- Inline Interface (`[KnockOff<IEntity>]`)
- Inline Class (`[KnockOff<SomeClass>]`)
- Stand-Alone/Flat (`[KnockOff]` on a class)

---

## Technical Details

Two changes were made to `FlatRenderer.cs`:

1. **`RenderInitPropertyInterceptorContent`**: Added `SetCount`, `LastSetValue`, and `RecordSet()` members to the generated interceptor class. Updated `Reset()` to clear set tracking state.

2. **`RenderPropertyImplementation`**: The `init` accessor now calls `RecordSet(value)` before storing the value:
   ```csharp
   // Before
   init { Id.Value = value; }

   // After
   init { Id.RecordSet(value); Id.Value = value; }
   ```

---

## Migration Guide

No migration required. This is a drop-in replacement for v10.22.0.

If you have standalone stubs with init-only properties, you now have access to `SetCount`, `LastSetValue`, and `RecordSet()` for verification.
