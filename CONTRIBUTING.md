# Contributing to KnockOff

Thank you for your interest in contributing to KnockOff. This document provides guidelines for contributing to the project.

## How to Contribute

### Reporting Issues

- Check existing issues before creating a new one
- Provide a clear description of the problem
- Include steps to reproduce the issue
- Share your environment details (.NET version, OS, IDE)
- Add code samples that demonstrate the issue

### Suggesting Features

- Open an issue describing the feature and its use case
- Explain why this feature would benefit KnockOff users
- Discuss the feature with maintainers before implementing

### Submitting Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes with clear, focused commits
4. Add tests for new functionality
5. Ensure all tests pass
6. Update documentation if needed
7. Submit a pull request to `main`

## Development Setup

```bash
git clone https://github.com/NeatooDotNet/KnockOff.git
cd KnockOff
dotnet restore
dotnet build
dotnet test
```

## Code Standards

- Follow existing code style and conventions
- Write clear, descriptive commit messages
- Add XML documentation for public APIs
- Keep changes focused and scoped to the issue

## Questions?

Join the discussion in [GitHub Discussions](https://github.com/NeatooDotNet/KnockOff/discussions) if you have questions about contributing.
